Modelo em Caixa, Model Box HTML

Os elementos html são estruturados em um modelo denominado modelbox, que refere-se a característica de um elemento poder conter outros elementos, sendo que cada um possui uma estrutura interna, similiar a ideia e uma caixa dentro de outra.

Estrutura de um elemento HTML

Todos os elementos HTML possuem conteúdo, padding, borda, offset. Sendo a região de conteúdo estruturada em três camadas 1) background-color 2) background-image 3) Content
