Origem do HTML

Linguagem de marcação criada por Tim Bernes Lee (1990) para compartilhamento no CERN

Arquitetura Cliente Servidor da WEB

As tecnologias que são fundamentais que compoem a web são:

  • Arquitetura Cliente Servidor
  • HTTP - Hyper Text Transfer Protocol
  • HTML - Hyper Text Markup Language
  • Navegador Cliente
  • Servidor Web

Ao longo dos anos a web evoluiu e novas tecnologias foram incorporadas como CSS e Javascript
